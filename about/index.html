技术经历

大模型工程化阶段（2024 - 至今）

聚焦大模型推理优化与企业级 AI 落地，核心工作包括：

  • 大模型分布式推理部署：基于 vLLM / SGLang 部署 235B MoE 大模型，多卡张量并行（TP）与专家并行（EP），FP8 量化，KV Cache 优化，高并发推理服务化
  • 推理性能调优：PagedAttention 显存管理、Continuous Batching 批量调度、投机解码、长上下文 KV Cache 压缩，关注吞吐、延迟与 GPU 利用率的平衡
  • AI Agent 工程化：从单 Agent 设计、Workflow 编排到 Multi-Agent 协作，MCP 协议统一工具接入，推动 Agent 从 Demo 走向企业业务落地
  • 企业级 AI 应用：RAG 知识库构建、文档智能解析（OCR / 表格 / 公式）、AI PaaS 平台架构设计、智能体应用开发

AI 应用与 NLP 阶段（2022 - 2024）

从计算机视觉转向自然语言处理与 AI 应用，核心工作包括：

  • 检索增强（RAG）系统：向量检索、混合检索、重排序（Rerank）、查询改写，企业知识库构建与优化
  • 文档理解与知识抽取：多格式文档解析（PDF / Word / PPT / 表格 / 图片），OCR 与版面分析，结构化信息提取
  • NLP 基础技术：词嵌入、文本分类、信息检索、序列标注，传统机器学习与深度学习文本模型

计算机视觉与基础算法阶段（2020 - 2022）

从数学与基础算法进入计算机视觉领域，核心工作包括：

  • 图像分类与目标检测：CNN 模型（AlexNet / VGG / ResNet / GoogLeNet），迁移学习，数据增强
  • 传统图像处理：图像预处理、特征提取、OpenCV 实战
  • 数学基础：线性代数、概率论与数理统计、最优化方法

技术成长路线

核心技术能力

大模型推理优化

  • 推理框架：vLLM、SGLang、TGI、FasterTransformer
  • 核心机制：PagedAttention、Continuous Batching、Chunked Prefill、Prefix Caching
  • KV Cache：MHA → MQA → GQA → MLA 演进，KV Cache 压缩与量化
  • 量化压缩：GPTQ、AWQ、FP8、DeepGEMM
  • 解码加速：投机解码、FlashAttention、FlashInfer
  • 分布式推理：张量并行（TP）、流水线并行（PP）、专家并行（EP）
  • 推理服务化：OpenAI 兼容 API、负载均衡、监控告警、容量规划

AI Agent 工程化

  • Agent 设计模式：ReAct、Plan-and-Execute、Reflexion、Agentic RAG
  • 多 Agent 协作：AutoGen、LangGraph、CrewAI，角色划分与通信机制
  • MCP 协议：Model Context Protocol，统一上下文与工具接入标准
  • Workflow 编排：DAG 编排、状态机、人机协同、错误恢复
  • 工具调用：Function Calling、结构化输出、参数校验
  • 上下文工程：Prompt 设计、上下文压缩、记忆机制

企业级 AI 应用

  • RAG 知识库：向量检索、混合检索、查询改写、Rerank 精排、答案溯源
  • 文档智能：多格式文档解析、版面分析、表格识别、公式识别、OCR
  • 多模态理解：视觉语言模型（VLM）、文档理解专用模型（PaddleOCR-VL / dots.ocr）
  • AI PaaS：模型服务化、智能体应用平台、企业知识库系统

AI 基础设施

  • GPU 集群：A100 / H20、NVLink / NVSwitch、NCCL 通信
  • 容器化：Docker、镜像构建、环境管理
  • 编排调度：Kubernetes、模型服务编排、自动扩缩容
  • 监控运维：GPU 利用率监控、推理指标监控、告警系统、容量规划

大模型架构与训练

  • 模型架构：Transformer、MoE、注意力机制、多模态、长上下文
  • 预训练：数据工程、优化器（AdamW / Muon）、混合精度
  • 后训练：SFT 监督微调、LoRA / QLoRA 参数高效适配
  • 对齐技术：RLHF、PPO、DPO、GRPO、奖励模型
  • 分布式训练：数据并行、张量并行、流水线并行、序列并行、自动并行
